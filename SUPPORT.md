# Support and community

This is experimental research software, not a commercial support service. Use GitHub Discussions (once enabled) for questions and ideas, Issues for reproducible bugs and board reports, and pull requests for reviewed code changes.

Before reporting a problem, include which component you ran (portable HTML, native observer, QEMU kernel), host OS, CPU architecture, browser or firmware version, commands, and exact observed output. Redact local paths, keys, passwords, serial numbers, personal data and proprietary logs.

For sensitive security matters, see [SECURITY.md](SECURITY.md). Do not assume a beta-quality OS driver or hardware feature exists unless recorded in the compatibility matrix with repeatable tests.
