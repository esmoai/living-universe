# Source provenance and responsible use

This public-source snapshot was assembled from the project owner's authorized Source / Destination and C-Native Kernel materials, plus AI-assisted implementation iterations. Files have been curated for source publication rather than uploading the original local backup bundle. The public repo contains code, a hash-checked original visual runtime, generated web-demo HTML, small authored sample inputs, and license notices.

The development process used ChatGPT-assisted code generation and tests. These tests do not constitute a security audit, hardware certification, human-computer-interaction evaluation or proof that the intended end-state OS exists. Source and third-party rights were reviewed at the packaging level, and the project owner should confirm ownership of all original contributions before substantial commercial redistribution.

The bundled Three.js code is open source under MIT terms and its notices are retained. The project-authored source is offered under Apache 2.0 only to the extent contributors have rights to license it. Third-party content is **not** relicensed by this project's Apache notice.

Not present in the repository: raw backup ZIPs, development handoff text, private captures, virtual-disk images, compiled native executables, Windows/Linux secrets, personal user paths, real serial logs, and browser workspaces. This is a source publication only.

The sample kernel serial log is an *authored fixture*, explicitly marked simulated. Actual firmware validation is pending. Public observations and demonstrations should always identify their source and uncertainty.
