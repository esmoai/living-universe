# Xputty Open Weight research build

This branch adds the independent application in `Xputty_Open_Weight/`. It does not modify Living Universe's kernel, runtime or browser bundle and grants no code kernel privileges.

Read `Xputty_Open_Weight/README.md` for installation and `Xputty_Open_Weight/docs/DISTILLATION-AND-QUANTIZATION.md` for actual experimental results and limitations. Xputty code retains its AGPL-3.0 license in that folder; this does not relicense the existing Apache-2.0 Living Universe project. Upstream models/data have their own recorded terms. No user transcripts, access keys or trained research weights are committed.

Select the Xputty devcontainer configuration to test it in Codespaces, or use its Windows/Linux/macOS launchers locally. A browser frontend on static hosting needs a separately running authenticated worker; GitHub Pages alone cannot train a model.
