# Changelog

## 0.3.0 — 2026-10-25 — Public-source preparation

- Packaged the Source / Destination visual field as a standalone interactive Living Universe prototype.
- Added 12-channel record overlay, exact byte/bit lens, annotations, local routing, curation and read-only temporal recall.
- Added opt-in renderer metrics, a loopback read-only hosted C observer and a versioned `@LU1` serial format from shared C kernel code.
- Retained x86-64 and AArch64 UEFI Stage 0 targets and QEMU test harness.
- Added source-only publication layout, third-party notices, issue/PR policies, security documentation and test workflows.
- Explicitly excluded raw user backup archives, generated firmware images, native binaries, captured local logs, credentials and runtime snapshots from version control.

**No production operating system or certified sandbox is claimed by this release.**
